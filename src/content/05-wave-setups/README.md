# Step 5: Wave Setups

Chart patterns and indicators tell you what price is doing. They are weak at telling you how mature a trend is. Is this rally just starting, or is it the last push before a fall? Wave analysis, based on the Elliott Wave Principle, helps answer that question.

This step does not try to make you an expert wave counter. It teaches the structure and the rules you need, then focuses on a handful of setups where the wave count gives a clear entry and a clear stop.

## Why use waves at all

Wave analysis helps you:

- **Find the main trend.** A five-wave advance is an uptrend.
- **Spot counter-trend moves.** A three-wave pullback inside an uptrend is a chance to buy in the trend's direction.
- **Judge maturity.** A fifth wave is a warning to take profit or tighten stops. The end of a C wave offers fresh entries.
- **Set targets.** Fibonacci relationships between waves give price targets.
- **Place better stops.** The wave rules tell you exactly which price would make your count wrong.
- **Filter setups.** A chart pattern that fits the wave count has better odds.

## How to use waves with the rest of the course

Use the three-screen method from Step 1 to make the decision. Use waves to filter setups, check them, and fine-tune the stop. Keep it simple, and trade only the clearest counts. When you are in doubt, do not trade.
